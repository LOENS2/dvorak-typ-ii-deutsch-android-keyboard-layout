# Dvorak Typ II Deutsch

The only implementation of the Dvorak Typ II German layout I could find was [this one](https://github.com/alphadev-net/dvde2-android).
The last commit to this repository was made in 2014, 
and I didn't bother to get it running, as it still uses the old Android Ant build system.

So I decided to create my own implementation.

## How it works

Creating a custom keyboard layout for Android is a straightforward process. 
You can create a keymap as a `.kcm` file and map the keys to the corresponding characters.

This is exactly what this app does.
